아이디어를
작동하는 AI로

완성된 모델을 구경하는 수업에서 벗어납니다. 학습자가 직접 데이터를 분류하고 조건을 조정하며 성능의 변화를 확인한 뒤, 블록 기반 앱과 파이썬으로 아이디어를 구현합니다.

01 · DATA

데이터 수집과 전처리

주제에 맞는 데이터를 모으고 학습에 적합한 형태로 분류·정리합니다.

02 · MODEL

모델 구성과 훈련

모델 구조와 설정값을 바꾸며 학습 결과와 오류를 비교합니다.

03 · BLOCK APP

블록 기반 앱 제작

기능 블록을 조합해 직접 만든 AI 모델을 활용하는 앱을 빠르게 구현합니다.

04 · GENERATIVE AI

생성형 AI 실험

프롬프트와 설정값을 바꾸며 결과가 달라지는 이유를 확인합니다.

05 · PYTHON

파이썬 실습

웹 기반 실습 환경에서 파이썬 기초부터 데이터와 AI를 활용하는 코딩까지 단계적으로 학습합니다.

06 · WORKSPACE

프로젝트와 수업 관리

과정 구성, 배포, 제출 현황, 결과물과 피드백을 같은 화면에서 관리합니다.
