딥코 스튜디오에서 만든 AI 모델과 카메라·센서 데이터를 실물 장치에 연결합니다. 데이터 수집부터 자동화 제어까지, 피지컬 AI 프로젝트를 한 키트로 완성합니다.

INPUT카메라·환경 센서
OUTPUT모터·서보·LED
CODE블록·파이썬

AI의 판단을
현실의 움직임으로

ESP32 기반 딥코 보드에 카메라와 환경 센서, 출력 장치를 연결합니다. 학습자는 데이터를 모으고 AI 모델을 만든 뒤, 판단 결과가 빛·소리·움직임으로 이어지는 과정을 직접 구현합니다.

01 · VISION

카메라가 보는 데이터

보드에 탑재된 카메라로 이미지를 수집하고 분류 모델의 판단을 실제 프로젝트에 적용합니다.

02 · SENSING

환경을 읽는 센서

온·습도, 조도, 초음파 센서로 교실과 생활 공간의 변화를 수치로 확인합니다.

03 · MOTION

모터로 만드는 움직임

DC모터와 서보모터를 제어해 회전, 방향 전환, 개폐 같은 동작을 구현합니다.

04 · SIGNAL

빛과 소리로 피드백

네오픽셀 LED, 3색 LED와 보드 내장 부저로 상태와 결과를 직관적으로 표현합니다.

05 · CONNECT

바로 연결하는 확장 구조

40핀 듀폰 케이블과 USB‑C 연결로 센서와 장치를 조합하며 프로젝트를 확장합니다.

06 · STUDIO

딥코 스튜디오와 연결

블록 기반 앱 제작과 파이썬 실습, AI 모델 학습을 하나의 프로젝트 흐름으로 이어갑니다.

데이터 수집, AI 판단, 장치 제어에 필요한 핵심 부품을 한 키트에 담았습니다. 구성품을 바꿔 연결하는 것만으로 수업 주제와 난이도를 유연하게 확장할 수 있습니다.

  6. 초음파 센서거리와 접근 감지

하나의 키트로
확장되는 수업

센서 하나를 연결하는 기초 실습부터 여러 데이터를 결합한 자동화 시스템까지, 학습자의 수준과 수업 목표에 맞춰 단계적으로 확장합니다.

01

스마트 교실

온·습도 데이터를 분석해 쾌적한 교실 환경을 알림으로 표현합니다.

02

자동 조명

주변 밝기를 감지하고 조건에 맞춰 LED의 색과 밝기를 제어합니다.

03

거리 안전 장치

초음파 센서로 접근 거리를 측정해 빛과 소리로 위험을 알립니다.

04

AI 분류 장치

카메라와 AI 모델의 분류 결과를 모터와 LED 동작으로 연결합니다.

05

스마트 환기

환경 데이터와 판단 조건에 따라 프로펠러를 자동으로 작동시킵니다.

06

나만의 피지컬 AI

센서와 출력 장치를 새롭게 조합해 생활 문제 해결 아이디어를 구현합니다.

데이터에서
피지컬 AI까지

관찰하고, 데이터를 모으고, AI의 판단을 장치 동작으로 연결합니다. 결과를 확인하며 조건과 모델을 개선하는 과정에서 데이터·AI·코딩·메이킹 역량을 함께 기릅니다.

01 · OBSERVE

문제 발견

생활 속 문제와 측정해야 할 환경 변화를 정합니다.

02 · COLLECT

데이터 수집

카메라와 센서로 데이터를 모으고 특징을 비교합니다.

03 · BUILD

AI·제어 설계

모델과 조건을 만들고 출력 장치의 동작을 설계합니다.

04 · IMPROVE

실행과 개선

실제 동작을 확인하며 데이터, 모델, 연결을 개선합니다.
